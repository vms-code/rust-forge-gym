Question: Which type signature permits register to take the widest variety of arguments?
Answer: B
Type: multiple-choice
Difficulty: 2
Tags: ergonomics, functions, functional-style

# Options
A. register1
B. register2

# Hint

# Explanation
Closures with environments can be passed to register2, while only top-level functions (or closures without environments) can be passed to register1.
